🚀 ЗАПУСК
────────────────────────────────────────────────────────────
Готовая сборка: откройте MDtoWORD.app (macOS) или MDtoWORD.exe (Windows).

Из исходников (Python 3.10 или новее):
   pip install -r requirements.txt
   python -m mdtoword


🎯 КАК ИСПОЛЬЗОВАТЬ
────────────────────────────────────────────────────────────
1. Перетащите в окно .md-файлы или целые папки
   (или нажмите «Добавить файлы» / «Добавить папку»).
2. При желании выберите шрифт, размер, стиль («Обычный» или
   «ГОСТ 7.32») и отметьте «Оглавление».
3. «Место сохранения»: по умолчанию результат кладётся рядом
   с исходником; «Выбрать папку» — всё в одну папку.
4. Нажмите «Конвертировать».
5. Предупреждения в итоговом окне указывают файл и строку:
   отчёт.md:42: Image not found: chart.png

Вкладка «Текст» — вставьте Markdown из буфера обмена и сохраните
.docx без исходного файла.
Переключатель «Режим» внизу меняет направление: Word → Markdown.


✨ ЧТО ПОДДЕРЖИВАЕТСЯ
────────────────────────────────────────────────────────────
✓ Заголовки (# … ######) с закладками; ссылки [текст](#заголовок)
✓ **жирный**, *курсив*, ~~зачёркнутый~~, `код`, H~2~O, x^2^, ==выделение==
✓ Списки с настоящей нумерацией Word, вложенные, с начала «5.»
✓ Чек-листы (- [ ] / - [x]) и списки определений
✓ Таблицы: выравнивание, форматирование и формулы в ячейках,
  подпись «Таблица: …» рядом с таблицей
✓ Изображения (PNG, JPEG, GIF, WebP, SVG…) — уменьшаются до ширины
  страницы; отдельная картинка становится рисунком с подписью
✓ Цитаты, плашки GitHub (> [!NOTE], > [!WARNING] …)
✓ Блоки кода
✓ Сноски [^1] — настоящие сноски Word внизу страницы
✓ Front matter (title, author, date, lang…) и [TOC] — оглавление
✓ Формулы LaTeX ($…$, $$…$$, align, aligned…) — родные уравнения Word
✓ Простой HTML: <br>, <sub>, <sup>, <kbd>, <mark>, <details>…


📝 НЕСКОЛЬКО ПРАВИЛ
────────────────────────────────────────────────────────────
- Абзацы разделяются пустой строкой. Одиночный перенос строки
  внутри абзаца — это пробел. Разрыв строки: два пробела или \
  в конце строки.
- Знак доллара в тексте пишите как \$ — иначе $…$ станет формулой.
- Номер формулы: $$ x = 1 $$ (1) или \tag{1} внутри формулы.


🎨 СТИЛЬ «ГОСТ 7.32»
────────────────────────────────────────────────────────────
A4, поля 30/15/20/20 мм, Times New Roman 14 pt, интервал 1,5,
абзацный отступ 1,25 см, «Рисунок N — …», «Таблица N — …»,
номер страницы внизу по центру.


❓ ЧАСТЫЕ ВОПРОСЫ
────────────────────────────────────────────────────────────
В: Word при открытии спрашивает, обновить ли поля?
О: В документе есть оглавление — разрешите, и Word добавит
   номера страниц.

В: Формула осталась текстом?
О: В итоговом окне указана строка и неподдерживаемая команда.
   Перепишите формулу через поддерживаемые конструкции (см. README).

В: Картинка не попала в документ?
О: Пути считаются от .md-файла. Если файла нет — вместо картинки
   будет [alt-текст] и предупреждение.
