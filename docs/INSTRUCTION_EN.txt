🚀 STARTING
────────────────────────────────────────────────────────────
Ready-made build: open MDtoWORD.app (macOS) or MDtoWORD.exe (Windows).

From source (Python 3.10 or newer):
   pip install -r requirements.txt
   python -m mdtoword


🎯 HOW TO USE
────────────────────────────────────────────────────────────
1. Drop .md files or whole folders onto the window
   (or press "Add files" / "Add folder").
2. Optionally pick the font, size, style ("Standard" or
   "GOST 7.32") and tick "Table of contents".
3. "Save location": by default each result goes next to its
   source; "Choose folder" sends everything to one folder.
4. Press "Convert".
5. Warnings in the result dialog name the file and line:
   report.md:42: Image not found: chart.png

The "Text" tab takes Markdown pasted from the clipboard and saves
a .docx without a source file.
The "Mode" switch in the footer flips the direction: Word → Markdown.


✨ WHAT IS SUPPORTED
────────────────────────────────────────────────────────────
✓ Headings (# … ######) with bookmarks; links [text](#heading)
✓ **bold**, *italic*, ~~strikethrough~~, `code`, H~2~O, x^2^, ==highlight==
✓ Lists with real Word numbering, nested, starting at "5."
✓ Task lists (- [ ] / - [x]) and definition lists
✓ Tables: alignment, formatting and formulas inside cells,
  a "Table: …" caption next to the table
✓ Images (PNG, JPEG, GIF, WebP, SVG…) — scaled to the page width;
  an image on its own becomes a captioned figure
✓ Blockquotes, GitHub alerts (> [!NOTE], > [!WARNING] …)
✓ Code blocks
✓ Footnotes [^1] — native Word footnotes at the bottom of the page
✓ Front matter (title, author, date, lang…) and [TOC] — a table of contents
✓ LaTeX formulas ($…$, $$…$$, align, aligned…) — native Word equations
✓ Simple HTML: <br>, <sub>, <sup>, <kbd>, <mark>, <details>…


📝 A FEW RULES
────────────────────────────────────────────────────────────
- Paragraphs are separated by a blank line. A single newline
  inside a paragraph is a space. Line break: two spaces or \
  at the end of the line.
- Write a literal dollar as \$ — otherwise $…$ becomes a formula.
- Equation number: $$ x = 1 $$ (1) or \tag{1} inside the formula.


🎨 THE "GOST 7.32" STYLE
────────────────────────────────────────────────────────────
A4, margins 30/15/20/20 mm, Times New Roman 14 pt, 1.5 spacing,
1.25 cm first-line indent, "Рисунок N — …", "Таблица N — …",
page number centred at the bottom.


❓ FAQ
────────────────────────────────────────────────────────────
Q: Word asks whether to update fields when opening the document?
A: The document has a table of contents — allow it and Word adds
   the page numbers.

Q: A formula stayed as text?
A: The result dialog names the line and the unsupported command.
   Rewrite the formula with supported constructs (see README).

Q: An image did not make it into the document?
A: Paths are relative to the .md file. If the file is missing,
   [alt text] appears instead, with a warning.
